# BoplMoreColors

Adds extra team colors to Bopl Battle so each of 5-8 players can be on their own unique team.

## What it does

The vanilla game has a limited color palette. With the FixedMoreBopl 8-player expansion, players 5+ must share colors (and therefore teams). This mod expands the palette with up to 12 additional visually distinct colors:

Orange, Pink, Cyan, Lime, Maroon, Teal, Gold, Lavender, Coral, Mint, Navy, Peach

## Configuration

Edit `BepInEx/config/com.geddesworks.boplmorecolors.cfg`:

- **ExtraColorCount** (0-12, default 8) — How many extra colors to add.
- **EnableDiagnostics** (default true) — Log color expansion details to BepInEx console.

## Requirements

- BepInEx 5.x
- Recommended: [FixedMoreBopl](https://thunderstore.io/c/bopl-battle/p/geddesworks/FixedMoreBopl/) for 5-8 player support
